# 小红书卡片生成器 v2 · 关键词直出工作流

把「**仅输入一个概念名**」变成「**可直接下载的小红书卡片图组**」。

> 相比原 v1：v1 必须先撰写完整文章，再让 AI 拼图。v2 跳过「写文章」这一步，AI 在内部完成「调研 → 结构化 → 排版」三段式，直接出图。

---

## 快速开始

### 方式 A · 一键启动（推荐）

```bash
cd xhs-generator
python3 server.py
# 浏览器自动打开 http://127.0.0.1:8765
```

`server.py` 同时承担两件事：
1. 把 `index.html` 当静态站点服务（解决 file:// 下的一些限制）
2. 提供 `/api/chat` 代理转发到 LLM 服务商，**彻底规避浏览器直连的跨域(CORS)问题**

### 方式 B · 直接双击 `index.html`

如果你的 LLM 服务商支持浏览器直连（如 DeepSeek），可以直接双击打开 `index.html`：
- 自动进入「直连模式」
- DeepSeek API Key 填入右侧「API Key」处即可

### 方式 C · 沿用原 v1（粘贴 Prompt 到 AI 对话）

如果不想用工具，直接读 `prompt-v2.md`，把其中「系统 Prompt」整段粘贴到任意 AI 对话窗口，后续每次输入主题即可。

## 工作流程

```
┌───────────────────────┐
│ 关键词 / 概念名         │  ← 你只输入这个
│   「魔弹论」            │
└──────────┬────────────┘
           ▼
   ┌───────────────────────────────────────┐
   │ ① 调研（LLM #1）                        │
   │   - 定义 / 背景 / 核心观点 / 例证 / 应用 / 争议│
   │   - 不确定事实移入 uncertain，绝不写入正文 │
   └──────────┬────────────────────────────┘
              ▼
   ┌───────────────────────────────────────┐
   │ ② 结构化（LLM #2）                       │
   │   - 按四步叙事剧本组织为 JSON 蓝图          │
   │   - 4–8 页 / 单页 ≤350 字 / 总字数 1300–1700│
   │   - 大标题用 <hl>核心词</hl> 局部强调       │
   └──────────┬────────────────────────────┘
              ▼
   ┌───────────────────────────────────────┐
   │ ③ 排版（确定性渲染引擎，无 LLM 介入）       │
   │   - 注入 écho 设计系统 CSS                 │
   │   - 严格按蓝图渲染为卡片 DOM                 │
   │   - 防溢出 / 防孤字 / 品牌资产锁死 / 尾页居中 │
   └──────────┬────────────────────────────┘
              ▼
   ┌───────────────────────────────────────┐
   │ 交付：横向卡片序列，一键下载 PNG / HTML / JSON│
   └───────────────────────────────────────┘
```

## 两种工作模式

| | 关键词直出（v2 新增） | 文章模式（沿用 v1） |
|---|---|---|
| 输入 | 概念名 / 主题 / 关键词 | 完整文章 / 素材 |
| LLM 调用 | 2 次（调研 + 结构化） | 1 次（结构化） |
| 适用 | 「魔弹论」「私域运营」这种成词概念 | 已写好的公众号/知乎/书摘长文 |
| 速度 | 慢 5–15s | 快 3–8s |

## 常见问题

**Q：浏览器直连 LLM 报跨域错误 / Failed to fetch 怎么办？**

**先分清情况**：不是所有服务商都允许浏览器直连。实测：**DeepSeek 支持**（返回 CORS 头），**腾讯 tokenhub（hunyuan）不支持**（预检 405 且无 CORS 头），OpenAI 域名在国内不可直连。

**解法（三选一）**：

1. **本机代理（最简单）**：`python3 server.py` 后访问 `http://127.0.0.1:8765`，本地服务会把请求转发给任何 LLM 服务商，无跨域问题。适合自己电脑上用。
2. **线上代理（GitHub Pages 上也能用）**：部署免费的 Cloudflare Worker（`cloudflare-worker.js`，部署步骤见文件头部注释，约 5 分钟），把得到的 `xxx.workers.dev` 地址填到工具「代理转发地址」输入框即可。
3. **换支持 CORS 的服务商**：DeepSeek 官方 API 支持浏览器直连，可先用它验证工具链路。

**Q：腾讯 tokenhub / 混元模型返回的内容解析失败？**

腾讯混元 hy3 等模型有时会把回复包成 `{"text":"..."}` 结构。工具已内置自适应解包逻辑（`unwrapText`），可自动识别并解出真实 JSON。若仍失败，请把「测试连接」输出发给我排查。

**Q：单页字数超 350 怎么办？**
A：界面顶部会显示 `⚠ N 页超字数`。可直接点「编辑 JSON」人工调整，或降低「页数」/「总字数」选项重新生成。

**Q：自定义品牌名怎么改？**
A：在「内容参数」→「品牌名」输入框修改（左下角显示）。最后重新生成或点击「应用」即生效。

**Q：演示页面的「魔弹论」是怎么生成的？**
A：`demo-content.json` 由我（AI 助手）按 v2 三段式流程手写产出，作为整套工作流的标准范例，可对照 `prompt-v2.md` 里的叙述剧本理解。

**Q：导出 PNG 黑屏/空白？**
A：99% 是 html2canvas 没加载成功（国内网络对 cdnjs 不稳定）。工具会自动回退到 `cdn.staticfile.org` 国内镜像；如果还是不行，请检查浏览器控制台网络。

**Q：能在小程序 / 移动端用吗？**
A：当前 `index.html` 适配桌面端浏览器（≥1280 宽）。移动端会拥挤但不影响导出 PNG。

## 与 v1 的核心差异

| | v1（飞书原文档） | v2（本工具） |
|---|---|---|
| 触发 | 用户先写好文章 → 粘贴 Prompt → AI 输出 HTML | 用户只输入关键词 → 工具自动调研+结构化 → 输出 PNG |
| 排版质量保证 | 依赖 LLM 一次性写对 HTML（容易溢出/排版漂移） | LLM 只负责内容 JSON，**排版由确定性引擎**渲染（不溢出） |
| 中间可编辑 | 无 | 可在「编辑 JSON」面板调整每页内容后重渲 |
| 导出 | 一键下载 PNG | **PNG + HTML + JSON** 三种导出 |
| 自定义品牌 | 锁定 `écho` | 工具内可改品牌名 |
